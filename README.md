# KIP Student Eligibility Prediction Website

**KIP Student Eligibility Prediction Website** is a web-based classification application developed using **Python** and **Streamlit** to predict student eligibility for the **KIP (Kartu Indonesia Pintar)** assistance program.

The application uses student data from **SMP Sepuluh November 02 Semarang** and applies the **Naive Bayes** algorithm to classify students based on predefined eligibility-related attributes.

## 🎓 About the Project

This project was developed to provide a structured solution for supporting student eligibility assessment for the KIP program.

Student data is processed and used to train a Naive Bayes classification model. The trained model is then integrated into a Streamlit-based web application, allowing eligibility predictions to be generated through a simple and accessible interface.

The platform is intended to support schools in organizing and evaluating student eligibility data more efficiently.

## 📊 Eligibility Prediction

The application processes student information and predicts eligibility for the KIP program using a trained **Naive Bayes** classification model.

User-provided student data is processed according to the model requirements before being classified into the corresponding eligibility category.

## 🗃️ Dataset

The dataset used in this project is based on student data from **SMP Sepuluh November 02 Semarang**.

The data provides the attributes required for preprocessing, model training, and classification of student eligibility for the KIP program.

## 🤖 Machine Learning Model

The classification model is implemented using the **Naive Bayes** algorithm.

The model analyzes relevant student attributes and generates an eligibility classification based on patterns identified within the training dataset.
